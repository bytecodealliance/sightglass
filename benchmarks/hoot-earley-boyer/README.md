# hoot-earley-boyer

Octane's `earley-boyer` benchmark, written in Scheme and compiled to WasmGC with
[Hoot](https://spritely.institute/hoot/). It runs both halves:

* **Earley**: Marc Feeley's Earley parser counts the parse trees of 9 `a`
  tokens under the ambiguous grammar `s -> a | s s` (1430 trees).
* **nboyer**: Bob Boyer's theorem prover, as revised by Will Clinger, rewrites a
  term with a table of lemmas and checks that it is a tautology (95024
  rewrites at size 0).

Both halves exercise allocation of pairs and vectors, list traversal, and
closures. Under Hoot that also means tail calls, `i31ref` fixnums, and WasmGC
structs and arrays.

## Origin

Octane's `earley-boyer.js` (JetStream commit
c603c04db8505477867974a69789309ded2cc948) was generated by scheme2js from these
Scheme benchmarks. The Scheme sources here come from the Gambit benchmark suite,
<https://github.com/gambit/gambit>, commit
d4d124d0555d03d46171c42522e3907a256e37cc:

* `earley.scm` is `bench/src/earley.scm` without its harness (`test`,
  `main`).
* `nboyer.scm` is `bench/src/nboyer.scm` without its harness (`main`). The
  lemma table is parsed from a string at startup, not quoted, because Hoot
  would build a quoted constant this large in one huge start function that
  would dominate Wasm compile time.

`main.scm` is the driver. It reads `earley-tokens earley-reps boyer-n
boyer-reps` from `default.input` (with a compiled-in fallback of `9 1 0 1`),
runs one untimed warm-up iteration of each half, then runs the timed iterations
between `bench.start` and `bench.end`.

## Build

Hoot (0.9.0, built against Guile 3.0.11) has no WASI target. Its output imports
its runtime from JavaScript (`rt`, `io`, `debug`). `link.sh` handles this by:

1. Implementing the imports the program needs in `host.wat` on top of WASI
   preview1: stdout/stderr, reading files through the preopened directory,
   and strings, which are passed as Hoot's own WTF-8 arrays and never
   converted.
2. Generating trapping stubs (`stubgen.awk`) for the rest: bignums,
   transcendental floats, and so on.
3. Merging everything with `wasm-merge`, exporting Hoot's `main` command entry
   point as `_start`, and making a component with the preview1 command adapter.

Binaryen runs with custom descriptors disabled; otherwise it emits exact
reference types, which Wasmtime rejects.

The driver avoids `read` and `display` because they roughly double the module
size.
