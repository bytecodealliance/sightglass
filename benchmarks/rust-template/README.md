# rust-template

Renders an HTML product catalog page with [MiniJinja] 2.24.0 (plus
`minijinja-contrib` for `truncate` and `wordcount`). MiniJinja is a widely used
Rust implementation of the Jinja2 template language, by Jinja2's author. Its
syntax and semantics are close to Jinja2's, so the templates here look like
those of a typical Python or Rust web app.

The templates in `templates/` use inheritance (`extends`/`block`/`super`),
`include`, imported macros, loops with `loop` variables, conditionals,
`groupby`, `selectattr`, `sort`, `map`/`sum`, `format`, and HTML auto-escaping.
The data, `rust-template.input.json`, is 140 synthetic products generated by
`generate_input.py` (deterministic; `python3 generate_input.py 140`).

The measured region covers converting the JSON data into a template value, then
parsing and compiling the templates and rendering the page, repeated as set by
`rust-template.iterations.input`. Including parsing models a cold start or
template reloading, and keeps the parser and compiler in the profile alongside
the interpreter. JSON parsing happens before `bench.start`. Prints the length
and FNV-1a hash of the HTML.

The environment registers only the filters, tests, and functions the templates
use (rather than `Environment::new`'s full set) to keep unused builtins out of
the binary and its compile time down.
